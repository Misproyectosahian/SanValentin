# 💌 San Valentín para Yanes

Una hermosa aplicación web interactiva creada con React para pedir ser el San Valentín de alguien especial.

## 🎨 Características

- **5 páginas animadas** con transiciones suaves
- **Lluvia de corazones** flotantes en cada página
- **Efectos interactivos** con hover y animaciones
- **Diseño responsivo** que se adapta a móviles y tablets
- **Tipografías elegantes** con fuentes personalizadas
- **Colores románticos** con degradados rosados y rojos

## 🚀 Instalación

### Requisitos previos
- Node.js (versión 14 o superior)
- npm o yarn

### Pasos de instalación

1. **Descargar y descomprimir el proyecto**
   
2. **Abrir una terminal** en la carpeta del proyecto

3. **Instalar las dependencias:**
   ```bash
   npm install
   ```

4. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

5. **Abrir el navegador** en la URL que aparece en la terminal (normalmente http://localhost:3000)

## 📱 Estructura del Proyecto

```
san-valentin-yanes/
├── package.json          # Dependencias y scripts
├── index.html           # HTML principal
├── vite.config.js       # Configuración de Vite
└── src/
    ├── main.jsx         # Punto de entrada de React
    ├── App.jsx          # Componente principal con todas las páginas
    └── App.css          # Estilos de la aplicación
```

## 🎭 Páginas de la Aplicación

1. **Página 1:** Carta cerrada con lluvia de corazones - Click para abrir
2. **Página 2:** Carta abierta estilo periódico con mensaje romántico
3. **Página 3:** 5 razones por las que es la elección perfecta
4. **Página 4:** La gran pregunta con botones interactivos
5. **Página 5:** Confirmación con explosión de corazones y mensaje final

## 🎨 Personalización

Para personalizar nombres, mensajes o colores, edita el archivo `src/App.jsx` y `src/App.css`.

## 📦 Compilar para Producción

Para crear una versión optimizada para producción:

```bash
npm run build
```

Los archivos compilados estarán en la carpeta `dist/`.
